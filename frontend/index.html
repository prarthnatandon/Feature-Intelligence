How It Works
📡
Data Collection
Fetches posts from r/duolingo via Reddit's public JSON API, reviews from Apple's App Store RSS feed, and a curated seed dataset — no authentication required.
⚡
Two-Wave Parallel Analysis
Wave 1: ThemeAgent and QuoteAgent run simultaneously. Wave 2: AIFeasibilityAgent and GapAgent use theme outputs to score AI solvability and map gaps against Duolingo's current feature set.
🧠
Extended Thinking Synthesis
The Orchestrator uses Claude's extended thinking with a 5,000-token reasoning budget to synthesize all four agent outputs into a prioritized Feature Opportunity Brief.
📋
Structured Output
Every opportunity is grounded in verbatim user quotes and ranked by evidence strength, AI uniqueness, and implementation effort.
